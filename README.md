# NOVA Programming Language

## Version
v1.8.2 — True Inheritance Edition

## Overview

NOVA is a lightweight programming language built from scratch in C.

The goal of NOVA is to provide a simple, educational, and expandable programming environment while gradually evolving into a more powerful language with modern features.

## Features

- Variables
- Functions
- Objects
- Classes
- Methods
- True Inheritance
- Database Engine
- CSV Engine
- Save Engine
- Script Engine
- Network Engine
- Tasks & Timers
- Interactive Runtime
- Nova.TeachGuide Learning System

## Installation

1. Download the latest release.
2. Extract the ZIP file.
3. Run `installer.exe`.
4. Wait for installation to finish.
5. Open Command Prompt.
6. Type:

```text
nova
```

7. Press Enter.

NOVA will start automatically.

## First Step

To learn NOVA, run:

```text
Nova.TeachGuide
```

## System Requirements

- Windows 10
- Windows 11
- x64 Architecture

Currently supported on Windows PC only.

## Project Vision

NOVA is an independent programming language project focused on learning, experimentation, and long-term evolution.

Future releases will continue expanding the language, runtime, tooling, and developer experience.
